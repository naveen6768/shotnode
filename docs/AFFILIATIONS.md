# Affiliation marks

The affiliations displayed on the home and About pages are defined in
`src/data/affiliations.ts`. Add a verified entry there and place its approved
mark in `public/supporters/`. Use the specific program name and relationship, rather
than a generic endorsement claim.

Current assets (downloaded October 26, 2026):

- `startup-india.png`: Startup India mark from the Government of India's
  [UXDT logo library](https://www.uxdt.nic.in/documents/logos/startup-india/).
  The same card identifies ShotNode's DPIIT recognition; DPIIT is not presented
  as a separate commercial sponsor.
- `claude.png`: Claude icon from [Claude](https://claude.com/apple-touch-icon.png).
- `google-cloud.svg`: Google Cloud logo served by
  [Google Cloud](https://www.gstatic.com/cgc/google-cloud-logo-fullcolor.svg).

Keep the underlying program acceptance and logo-use approvals with the company's
brand records. Do not add an affiliation to the public list before it is verified.
